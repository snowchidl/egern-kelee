# Egern自用配置

个人自用的 Egern 模块仓库，存放日常在用的去广告、功能增强与实用小模块。

## 目录

- `modules/`：模块文件（`.sgmodule`），在 Egern 里以远程模块方式添加即可使用。
- `js/`：模块配套的 JS 脚本文件，模块会自动引用，无需单独处理。
- `extras/`：自托管的定制与预设模块，包括哔哩哔哩助手预设版、YouTube 双语字幕修复版、IP 质检小组件、知乎定制版（放行相关回答）、贴吧签到，以及 Privacy 反追踪规则集等。

## 使用

把需要的模块文件链接复制到 Egern 的「模块」里添加，开启即可。配置文件本体涉及个人订阅信息，不在本仓库存放。
